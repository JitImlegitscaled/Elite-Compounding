> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add dark mode with localStorage persistence, a page-load skeleton shimmer overlay, and enhanced CSS animations (staggered cards, hero entrance sequence, nav spring, button press) to the Elite Compounding Agency marketing site.

**Architecture:** All changes are additive edits to a single `index.html` file. Dark mode is CSS-variable-based, driven by a `data-theme="dark"` attribute on `<html>`. Skeleton is a `<div id="skeleton-overlay">` injected as the first child of `<body>`. Animation enhancements extend the existing `IntersectionObserver` reveal system and add new CSS classes/states.

**Tech Stack:** Vanilla HTML, CSS, JavaScript. No new dependencies. No build step.

## Task 1: Flash-prevention script + dark mode CSS tokens

**Files:**
- Modify: `index.html` — `<head>` section (add inline script before stylesheets) and `<style>` block (add dark token overrides + smooth transitions)

- [ ] **Step 1: Add the flash-prevention inline script**

  In `index.html`, locate the opening `<head>` tag (line 3). Insert this inline `<script>` as the very first child of `<head>`, before the `<meta charset>` tag:

  ```html
  <script>
    (function() {
      var saved = localStorage.getItem('theme');
      var prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
      if (saved === 'dark' || (!saved && prefersDark)) {
        document.documentElement.setAttribute('data-theme', 'dark');
      }
    })();
  </script>
  ```

  This must be the first thing in `<head>` — before any CSS — so it runs synchronously before the browser paints, preventing a flash of the wrong theme.

- [ ] **Step 3: Add toggle JavaScript**

  In the `<script>` block at the bottom of the file (around line 1846), add after the nav scroll listener:

  ```js
  // ── Theme toggle
  const themeToggle = document.getElementById('theme-toggle');
  function applyTheme(theme) {
    if (theme === 'dark') {
      document.documentElement.setAttribute('data-theme', 'dark');
      themeToggle.textContent = '☀';
      themeToggle.setAttribute('aria-label', 'Switch to light mode');
    } else {
      document.documentElement.removeAttribute('data-theme');
      themeToggle.textContent = '☾';
      themeToggle.setAttribute('aria-label', 'Switch to dark mode');
    }
  }
  // Sync icon to current state on load
  const currentTheme = document.documentElement.getAttribute('data-theme');
  applyTheme(currentTheme === 'dark' ? 'dark' : 'light');

  themeToggle.addEventListener('click', () => {
    const isDark = document.documentElement.getAttribute('data-theme') === 'dark';
    const next = isDark ? 'light' : 'dark';
    localStorage.setItem('theme', next);
    applyTheme(next);
  });
  ```

  Replace the entire block with:

  ```js
  const revealEls = document.querySelectorAll('.reveal');
  const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
      if (entry.isIntersecting) {
        if (entry.target.hasAttribute('data-stagger-children')) {
          Array.from(entry.target.children).forEach((child, i) => {
            child.style.transitionDelay = (i * 80) + 'ms';
            child.classList.add('visible');
          });
        } else {
          entry.target.classList.add('visible');
        }
        observer.unobserve(entry.target);
      }
    });
  }, { threshold: 0.12, rootMargin: '0px 0px -40px 0px' });

  revealEls.forEach(el => observer.observe(el));

  // Observe stagger containers
  document.querySelectorAll('[data-stagger-children]').forEach(el => observer.observe(el));
  ```
